# Suporte — Aplicativo Mibro Fit

## Objetivo

Este arquivo orienta o Bot sobre dúvidas e problemas relacionados ao aplicativo oficial Mibro Fit.

Assuntos cobertos:

- instalação
- login
- conexão com relógio
- sincronização
- permissões
- notificações
- atualização
- execução em segundo plano
- troca de celular
- problemas gerais do aplicativo

---

# Aplicativo oficial

Para os smartwatches Mibro desta Knowledge, o aplicativo oficial utilizado é:

Mibro Fit

O Bot não deve recomendar aplicativos de terceiros para substituir o Mibro Fit.

---

# Quando usar este arquivo

Consultar quando o cliente mencionar:

- Mibro Fit
- aplicativo não abre
- aplicativo não conecta
- aplicativo não encontra relógio
- dados não sincronizam
- notificações não chegam
- aplicativo fecha sozinho
- aplicativo desconecta
- troca de celular
- login
- conta
- permissões
- atualização do relógio

---

# Instalação

O cliente deve utilizar a versão oficial do Mibro Fit disponível para seu sistema operacional.

Evitar recomendar:

- APK de sites desconhecidos
- aplicativos modificados
- lojas não oficiais
- versões piratas

Se o aplicativo oficial não estiver disponível ou houver erro de instalação persistente:

encaminhar para suporte humano.

---

# Compatibilidade

Os requisitos podem variar conforme o modelo do smartwatch.

Muitos modelos desta Knowledge possuem compatibilidade informada com:

- Android 5.0 ou superior
- iOS 10.0 ou superior

Entretanto:

consultar o arquivo individual do produto quando o cliente perguntar sobre compatibilidade específica.

Não generalizar requisitos de um modelo para todos.

---

# Primeiro acesso

Quando o cliente estiver configurando o Mibro Fit pela primeira vez:

1. instalar o aplicativo oficial;
2. abrir o aplicativo;
3. criar conta ou entrar quando solicitado;
4. conceder as permissões necessárias;
5. adicionar o relógio pela área de dispositivos;
6. concluir o pareamento.

Os nomes exatos de menus podem variar conforme a versão do aplicativo.

O Bot não deve inventar nomes exatos de botões se não tiver confirmação.

---

# Login

Se o cliente não consegue entrar:

verificar:

- e-mail/conta utilizados
- senha
- conexão com internet
- se está utilizando a mesma conta anterior
- mensagem de erro exibida

Não pedir senha ao cliente.

Nunca solicitar:

- senha
- código de autenticação
- token
- dados bancários

---

# Esqueci a senha

Se o cliente esqueceu a senha:

orientar a utilizar a opção oficial de recuperação de conta disponível no aplicativo.

Não tentar criar ou sugerir senhas.

Se a recuperação não funcionar:

encaminhar para suporte humano.

---

# Troca de celular

Quando o cliente trocar de smartphone:

1. instalar o Mibro Fit no novo aparelho;
2. entrar na conta correta;
3. verificar se o relógio ainda está vinculado ao aparelho anterior;
4. remover vínculo antigo quando necessário;
5. realizar novo pareamento pelo Mibro Fit.

Se o relógio continuar preso ao celular/conta anterior:

consultar o fluxo de:

03_Suporte/conexao-pareamento.md

---

# Permissões

O Mibro Fit pode precisar de diferentes permissões para funcionar corretamente.

Entre elas podem estar:

- Bluetooth
- dispositivos próximos
- localização
- notificações
- câmera
- execução em segundo plano

A necessidade exata depende:

- do sistema operacional
- da versão do Android/iOS
- da função utilizada

Não orientar o cliente a liberar permissões desnecessárias sem relação com o problema.

---

# Bluetooth

O Bluetooth é necessário para comunicação entre relógio e smartphone.

Se o relógio não sincroniza:

verificar:

- Bluetooth ativo
- dispositivo próximo
- Mibro Fit aberto
- relógio conectado ao aplicativo
- vínculo antigo

Para problemas de pareamento, consultar:

03_Suporte/conexao-pareamento.md

---

# Sincronização

Se os dados não aparecem no aplicativo:

1. confirmar conexão Bluetooth;
2. abrir o Mibro Fit;
3. manter relógio próximo;
4. aguardar sincronização;
5. verificar se o relógio aparece como conectado;
6. conferir conexão com internet quando necessária.

Se continuar sem sincronizar:

verificar possíveis restrições de segundo plano.

---

# Dados que podem sincronizar

Dependendo do modelo e funções disponíveis, o Mibro Fit pode sincronizar informações como:

- atividades
- sono
- frequência cardíaca
- SpO₂
- esportes
- configurações
- mostradores
- notificações

Não afirmar que todo modelo sincroniza exatamente os mesmos dados.

Consultar o arquivo individual.

---

# Execução em segundo plano — Android

Alguns celulares Android encerram aplicativos para economizar bateria.

Isso pode causar:

- perda de conexão
- falha em notificações
- sincronização atrasada
- relógio desconectando

Quando necessário, orientar o cliente a verificar as configurações de:

- bateria
- aplicativos em segundo plano
- inicialização automática
- otimização de bateria

Os nomes variam por fabricante.

Não inventar caminho exato se o modelo do celular não estiver confirmado.

---

# Samsung

Em celulares Samsung, recursos de economia de bateria podem limitar aplicativos em segundo plano.

Se necessário, orientar o cliente a verificar se o Mibro Fit está sendo colocado em modo de suspensão.

Não informar caminhos específicos sem confirmação da versão do sistema.

---

# Xiaomi / Redmi / Poco

Esses aparelhos podem aplicar restrições agressivas de bateria e inicialização em segundo plano.

Quando houver perda constante de conexão:

verificar se o Mibro Fit possui permissão para permanecer ativo.

Não recomendar desativar recursos de segurança do sistema.

---

# Motorola

Se houver falha de notificações ou sincronização:

verificar permissões do aplicativo e otimização de bateria.

---

# iPhone

No iPhone, verificar quando necessário:

- Bluetooth
- notificações
- atualização em segundo plano
- permissões do aplicativo

O comportamento pode mudar conforme a versão do iOS.

---

# Notificações

Se o cliente recebe dados no Mibro Fit, mas não recebe notificações no relógio:

consultar:

03_Suporte/notificacoes.md

Não misturar automaticamente problema de sincronização com problema de notificações.

---

# Clima

Se o clima não aparece ou não atualiza:

verificar:

- conexão com internet
- conexão entre celular e relógio
- permissões necessárias
- localização quando aplicável
- sincronização do Mibro Fit

Se persistir:

encaminhar para suporte.

---

# Mostradores

O Mibro Fit pode oferecer:

- seleção de mostradores
- personalização
- sincronização de watchfaces

A quantidade e tipos disponíveis variam conforme o modelo.

Não prometer que um mostrador de outro modelo é compatível.

---

# Instalação de mostrador

Se o cliente tiver problema para instalar um mostrador:

1. verificar conexão do relógio;
2. manter o relógio próximo;
3. verificar bateria suficiente;
4. manter o aplicativo aberto durante o processo;
5. aguardar a transferência.

Evitar interromper o processo.

---

# Atualização OTA

Diversos modelos suportam atualização OTA pelo aplicativo.

OTA significa atualização de firmware sem cabo de dados.

Antes de atualizar:

- manter bateria suficiente
- manter relógio próximo ao celular
- manter Bluetooth ativo
- evitar fechar o aplicativo
- evitar desligar relógio ou celular

Não recomendar atualização com bateria muito baixa.

---

# Atualização travada

Se uma atualização ficar travada:

não orientar desligamento imediato sem avaliar a situação.

Perguntar:

- percentual em que parou
- há quanto tempo
- relógio responde?
- aplicativo mostra erro?

Se parecer realmente travada ou houver risco de falha:

encaminhar para suporte humano.

---

# Atualização falhou

Se o aplicativo informar falha:

1. verificar conexão Bluetooth;
2. verificar internet;
3. verificar bateria;
4. reiniciar o Mibro Fit;
5. tentar novamente apenas se o relógio estiver funcionando normalmente.

Se a falha repetir:

encaminhar para suporte.

---

# Aplicativo fecha sozinho

Se o Mibro Fit fecha:

verificar:

- atualização disponível
- espaço livre no celular
- sistema operacional
- reinicialização do smartphone

Evitar orientar limpeza de dados imediatamente se isso puder apagar configurações ou sessão.

Se persistir:

encaminhar para suporte.

---

# Limpar cache

Em Android, limpeza de cache pode ser considerada quando houver comportamento anormal do aplicativo.

IMPORTANTE:

cache e dados do aplicativo são diferentes.

Não orientar "limpar dados" como primeira tentativa.

Limpar dados pode:

- encerrar sessão
- remover configurações locais
- exigir novo login
- exigir novo pareamento

---

# Desinstalar e reinstalar

Reinstalação pode ser utilizada quando:

- aplicativo apresenta falhas persistentes
- outras verificações simples não resolveram

Antes:

verificar se o cliente possui acesso à conta utilizada.

Não orientar reinstalação se isso puder deixar o cliente sem acesso à conta.

---

# Relógio aparece offline

Se o aplicativo mostra relógio offline:

verificar:

- Bluetooth
- distância
- bateria do relógio
- aplicativo em segundo plano
- conexão anterior
- outro celular conectado

Se persistir:

consultar conexão-pareamento.md.

---

# Múltiplos relógios

Se o cliente utilizar mais de um smartwatch:

não presumir que todos podem permanecer ativos simultaneamente.

Consultar comportamento atual do Mibro Fit quando necessário.

Se não houver informação na Knowledge:

encaminhar para humano.

---

# Dados antigos

Se o cliente perguntar sobre dados históricos:

não garantir recuperação de informações que não estejam sincronizadas com a conta.

Dados locais podem depender de:

- sincronização anterior
- conta
- dispositivo
- versão do aplicativo

Se houver perda de histórico importante:

encaminhar para suporte.

Consultar o arquivo do produto.

---

# Google Fit

Alguns modelos podem oferecer integração com Google Fit.

Não afirmar compatibilidade para todos.

Consultar o arquivo individual.

---

# Strava

Alguns modelos oferecem integração com Strava.

Exemplos confirmados nesta Knowledge incluem determinados modelos Professional e lançamentos.

Não generalizar para toda a linha Mibro.

---

# Problemas com integração externa

Se o cliente relatar falha entre Mibro Fit e:

- Strava
- Apple Health
- Google Fit

primeiro confirmar:

- modelo do relógio
- se a integração é oficialmente suportada
- se a conta foi conectada corretamente

Não prometer sincronização bidirecional sem confirmação.

---

# Privacidade e dados

O Bot não deve pedir:

- senha
- token
- código de autenticação
- credenciais completas

Se for necessário coletar e-mail de conta para suporte humano, seguir apenas o fluxo autorizado da Central.

---

# Não pedir tudo de uma vez

Evitar transformar o atendimento em formulário.

Exemplo ruim:

"Informe modelo, celular, Android, versão, conta, erro, país e versão do app."

Preferir:

"Qual problema está acontecendo no Mibro Fit?"

Depois perguntar apenas o que faltar.

---

# Exemplo — aplicativo não conecta

Cliente:

"O Mibro Fit não conecta no meu GS Pro 2."

Bot:

"Ele encontra o GS Pro 2 na busca do aplicativo ou o relógio nem aparece?"

A resposta define o próximo passo.

---

# Exemplo — dados não sincronizam

Cliente:

"Meu sono não aparece no app."

Bot:

"O relógio aparece como conectado no Mibro Fit agora?"

Se sim:

seguir para sincronização/dados.

Se não:

seguir para conexão.

---

# Exemplo — app fecha

Cliente:

"O Mibro Fit fecha sozinho."

Bot:

"Isso começou depois de alguma atualização ou já acontecia antes?"

Depois verificar versão/app/sistema.

---

# Quando encaminhar para humano

Encaminhar quando:

- login não funciona após recuperação
- conta parece bloqueada
- relógio preso a outra conta
- atualização falha repetidamente
- atualização aparentemente travada
- dados importantes desapareceram
- integração oficial não funciona
- aplicativo fecha repetidamente
- comportamento não documentado
- cliente não consegue concluir pareamento
- problema persiste após verificações básicas

---

# Informações úteis antes do handoff

Coletar apenas quando relevante:

- modelo do relógio
- Android ou iPhone
- modelo do celular
- problema no Mibro Fit
- mensagem de erro
- se já funcionava antes
- procedimentos realizados
- resultado
- versão do aplicativo, quando realmente necessária

---

# Resumo para humano

Exemplo:

Setor: Suporte
Assunto: Mibro Fit / Sincronização
Modelo: Lite 3 Pro
Celular: Android
Problema: relógio conecta, mas atividades não sincronizam
Já verificado: Bluetooth ativo, app conectado, reinício realizado
Resultado: continua sem sincronizar
Pendência: análise humana

---

# O que o Bot pode fazer

Pode:

- orientar instalação oficial
- orientar permissões básicas
- verificar Bluetooth
- orientar sincronização
- verificar restrições de bateria
- orientar atualização segura
- direcionar para fluxos específicos

---

# O que o Bot NÃO deve fazer

Não deve:

- pedir senha
- pedir token
- recomendar APK desconhecido
- inventar menus
- garantir recuperação de dados
- recomendar limpeza total de dados sem necessidade
- mandar resetar relógio como primeira tentativa
- inventar compatibilidade de integrações
- prometer correção de conta

---

# Regra final

O objetivo é resolver rapidamente problemas simples e identificar quando a situação exige atendimento humano.

O cliente não deve precisar repetir todas as informações quando houver handoff.
