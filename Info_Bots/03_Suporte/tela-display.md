# Suporte — Tela e Display

## Objetivo

Este arquivo orienta o Bot sobre problemas relacionados a:

- tela preta
- tela não acende
- toque não responde
- tela piscando
- brilho muito baixo
- brilho muito alto
- AOD
- manchas
- linhas na tela
- pixels aparentes
- vidro quebrado
- tela trincada
- display com falha parcial
- tela acende e apaga sozinha

O Bot deve diferenciar problemas de software/configuração de possíveis danos físicos.

---

# Regra principal

Antes de assumir defeito físico, verificar:

- bateria
- carregamento
- brilho
- modo Não Perturbe
- AOD
- reinicialização simples
- atualização
- comportamento recente

Mas, se houver:

- vidro quebrado
- trinca
- manchas
- linhas persistentes
- tela descolando
- dano após impacto
- dano após água

encaminhar para avaliação humana.

---

# Primeiro atendimento

Se o cliente disser:

"A tela não funciona."

Perguntar de forma natural:

"Ela está totalmente apagada ou chega a acender, mas o toque não responde?"

Isso separa:

- tela preta
- falha de toque
- falha parcial

---

# Tela totalmente preta

Se o relógio não mostra nada:

1. verificar se há bateria;
2. conectar ao carregador adequado;
3. observar se aparece sinal de carregamento;
4. tentar reinicialização simples, se o modelo permitir.

Se não houver qualquer resposta:

consultar também:

03_Suporte/carregamento.md

Se continuar sem sinal:

encaminhar para suporte humano.

---

# Relógio vibra, mas tela não acende

Se há vibração ou som, mas a tela permanece preta:

isso pode indicar problema específico de display ou software.

Orientar:

- reinicialização simples
- verificar se houve queda/impacto
- verificar se houve água
- verificar se começou após atualização

Se persistir:

encaminhar.

---

# Tela acende, mas toque não responde

Verificar:

- se há película danificada
- se a tela está molhada
- se há sujeira
- se o relógio está travado
- se o problema começou após impacto

Pode orientar:

- secar a tela
- limpar suavemente
- reiniciar o relógio

Não recomendar objetos pontiagudos ou pressão excessiva.

Se continuar sem resposta:

encaminhar.

---

# Tela molhada

Água na superfície pode afetar temporariamente o toque.

Orientar:

- secar completamente
- evitar manipular com tela molhada
- não carregar se os contatos também estiverem molhados

Se o problema persistir depois de seco:

encaminhar.

---

# Tela piscando

Se a tela pisca:

verificar:

- bateria muito baixa
- atualização recente
- brilho
- reinicialização
- possível impacto
- superaquecimento

Se a oscilação continuar:

encaminhar para suporte.

---

# Linhas na tela

Linhas verticais ou horizontais persistentes podem indicar problema no display.

Não tentar corrigir com:

- pressão
- pancadas
- calor
- abertura do relógio

Encaminhar para avaliação humana.

---

# Manchas

Se houver:

- manchas escuras
- manchas coloridas
- áreas sem imagem
- vazamento aparente no display

encaminhar para suporte.

Isso pode indicar dano físico interno do display.

---

# Pixels

Se o cliente relatar ponto fixo claro/escuro:

não diagnosticar automaticamente.

Perguntar se:

- aparece sempre
- aparece em qualquer tela
- surgiu após impacto

Se persistente:

encaminhar para avaliação.

---

# Tela quebrada ou trincada

Se houver:

- vidro quebrado
- trinca
- lasca
- impacto

não orientar reparo caseiro.

Encaminhar para suporte humano.

O Bot NÃO deve afirmar que o dano está coberto pela garantia.

---

# Tela descolando

Se a tela parece levantar ou descolar:

interromper uso se houver qualquer sinal de:

- bateria estufada
- deformação
- aquecimento

Não pressionar a tela de volta.

Encaminhar imediatamente.

---

# Brilho baixo

Se a tela funciona, mas parece muito escura:

verificar:

- nível de brilho
- modo economia
- AOD
- sensor de luz, quando o modelo possuir
- modo noturno
- bateria

Não assumir defeito antes de verificar configuração.

---

# Brilho automático

Alguns modelos possuem sensor de luz.

Não generalizar para todos.

Consultar o arquivo individual antes de afirmar que o modelo possui brilho automático.

---

# Brilho alto demais

Orientar ajuste pelo próprio relógio ou aplicativo, quando disponível.

Não inventar caminho exato de menu sem confirmação.

---

# AOD

AOD significa Always-On Display.

Modelos confirmados nesta Knowledge incluem alguns como:

- Lite 3
- Lite 3 Pro
- GS Pro
- GS Pro 2

Consultar o arquivo individual para confirmar.

AOD pode:

- manter informações visíveis
- aumentar consumo de bateria

Se o cliente disser que a tela "não apaga":

verificar se AOD está ativado.

---

# Tela não apaga

Possíveis causas:

- AOD
- atividade esportiva
- configuração de tempo de tela
- comportamento do sistema

Primeiro verificar AOD e configurações.

Não assumir falha.

---

# Tela apaga rápido demais

Verificar:

- tempo de tela
- economia de bateria
- configuração do relógio

Não prometer que todos os modelos permitem ajustar o tempo da mesma forma.

---

# Relógio acende sozinho

Pode ocorrer por:

- levantar pulso
- notificações
- chamadas
- atividade
- gesto de ativação

Se acontece constantemente sem motivo aparente:

verificar configuração e encaminhar se persistir.

---

# Gesto de levantar o pulso

Alguns modelos podem ativar a tela ao levantar o pulso.

Se isso estiver causando incômodo:

orientar a verificar configurações do relógio/Mibro Fit.

Não afirmar o nome exato do menu sem confirmação.

---

# Tela durante exercício

Alguns modos esportivos podem manter ou alterar o comportamento da tela.

Não tratar isso automaticamente como defeito.

---

# Tela congelada

Se a tela mostra imagem, mas não responde:

orientar reinicialização simples.

Se reiniciar e voltar ao normal:

observar.

Se trava frequentemente:

encaminhar.

---

# Reinicialização simples

Reiniciar o relógio pode ajudar em:

- travamento
- toque sem resposta
- tela congelada
- falha temporária

Isso não é reset de fábrica.

---

# Reset de fábrica

Não usar como primeira tentativa.

Pode apagar:

- configurações
- vínculos
- dados locais

Só orientar quando houver procedimento oficial e necessidade real.

---

# Atualização

Se o problema começou após atualização:

coletar:

- modelo
- quando atualizou
- comportamento antes/depois
- se reiniciou

Se persistir:

encaminhar.

---

# Impacto ou queda

Se a falha começou após:

- queda
- batida
- pancada

considerar possível dano físico.

Não diagnosticar extensão do dano.

Encaminhar.

---

# Água

Se o problema começou após contato com água:

perguntar:

- modelo
- tipo de contato
- se foi água quente
- se houve vapor
- se estava em piscina/mar
- quando aconteceu

Não afirmar cobertura de garantia.

Encaminhar quando houver falha persistente.

---

# Água quente e vapor

Mesmo modelos resistentes à água não devem ser tratados como seguros em:

- sauna
- vapor
- banho quente
- hidromassagem

Se a tela apresentou falha após isso:

registrar contexto e encaminhar.

---

# Tela após carregamento

Se a tela só falha durante carregamento:

verificar:

- fonte
- carregador
- aquecimento
- mau contato

Se houver aquecimento anormal:

interromper carregamento e encaminhar.

---

# Tela após bateria zerar

Se apagou após descarregar completamente:

seguir primeiro:

03_Suporte/carregamento.md

Se voltar a carregar, mas tela não responde:

encaminhar.

---

# Película

Películas mal instaladas podem afetar:

- toque
- sensibilidade
- aparência
- bolhas

Se o problema começou após colocar película:

considerar essa possibilidade.

Não mandar remover se houver risco de dano sem necessidade.

---

# Capa/protetor

Acessórios muito apertados podem interferir em botões ou bordas.

Se o problema começou após colocar acessório:

orientar teste sem o acessório, se seguro.

---

# Botão físico

Se a tela não acende pelo botão:

verificar se:

- tela responde por gesto
- carregamento funciona
- botão parece preso

Se botão estiver fisicamente quebrado:

encaminhar.

---

# Exemplo — tela preta

Cliente:

"Meu Lite 3 ficou com a tela preta."

Bot:

"Ele ainda vibra ou dá algum sinal quando você coloca para carregar?"

Se não:

seguir para carregamento.

Se sim:

avaliar display.

---

# Exemplo — toque não funciona

Cliente:

"A tela acende, mas não consigo tocar em nada."

Bot:

"Ela está seca e sem película danificada? Se sim, tente reiniciar o relógio. Se o toque continuar sem responder, o ideal é encaminhar para avaliação."

---

# Exemplo — linhas

Cliente:

"Apareceram linhas verdes na tela."

Bot:

"Se essas linhas ficam visíveis o tempo todo, pode ser uma falha do display. Não tente pressionar ou abrir o relógio; vou encaminhar para avaliação do suporte."

---

# Exemplo — tela quebrada

Cliente:

"Quebrei a tela."

Bot:

"Entendi. Nesse caso é necessária uma avaliação física. Vou encaminhar para o suporte verificar as opções disponíveis."

Não dizer:

"Está fora da garantia."

A avaliação deve ser humana.

---

# Quando encaminhar imediatamente

Encaminhar quando houver:

- tela quebrada
- trinca
- tela descolando
- bateria aparentemente estufada
- manchas persistentes
- linhas persistentes
- dano após impacto
- superaquecimento
- possível entrada de líquido
- cheiro estranho
- deformação

---

# Quando encaminhar após verificações básicas

Encaminhar quando:

- tela continua preta com bateria
- toque continua sem responder
- tela pisca constantemente
- trava repetidamente
- brilho fica anormal sem causa aparente
- problema começou após atualização e persiste
- comportamento não documentado

---

# Informações úteis antes do handoff

Coletar quando relevante:

- modelo
- tela acende ou não
- toque funciona ou não
- houve queda
- houve contato com água
- houve atualização
- há linhas/manchas
- há aquecimento
- data aproximada da compra
- NF/comprovante

---

# Resumo para humano

Exemplo:

Setor: Suporte
Assunto: Tela / Display
Modelo: Lite 3 Pro
Problema: tela acende, mas toque não responde
Queda: não
Água: não
Já realizado: reinicialização simples
Resultado: sem alteração
Pendência: avaliação do display/touch

---

# O que o Bot pode fazer

Pode:

- distinguir tela preta de touch
- verificar bateria
- verificar brilho
- verificar AOD
- orientar secagem
- orientar reinicialização simples
- identificar possível dano físico
- encaminhar

---

# O que o Bot NÃO deve fazer

Não deve:

- recomendar abrir o relógio
- pressionar display
- usar calor
- usar produtos químicos
- garantir reparo
- afirmar cobertura de garantia
- mandar resetar como primeira tentativa
- diagnosticar bateria estufada sem sinais
- afirmar defeito físico sem contexto

---

# Regra final

Se houver sinal físico visível ou risco de segurança:

parar os testes e encaminhar.

Se parecer software/configuração:

fazer apenas verificações simples e seguras.
