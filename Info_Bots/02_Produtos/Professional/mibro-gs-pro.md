# Mibro GS Pro

## Visão geral

O Mibro GS Pro é um smartwatch da linha Professional da Mibro, desenvolvido com foco em atividades esportivas, navegação, posicionamento por satélite e uso diário.

Entre os principais recursos estão:

- tela AMOLED de 1,43"
- resolução de 466 × 466 pixels
- brilho informado de até 1200 nits
- estrutura em aço inoxidável 316L
- GPS e sistemas globais de posicionamento
- navegação de rota
- triatlo
- 105 modos esportivos
- resistência à água de 5 ATM
- chamadas Bluetooth
- Bluetooth 5.3
- bússola
- altitude e pressão atmosférica
- NFC
- AOD
- monitoramento diário
- aplicativo Mibro Fit

## Suporte inicial — GPS

Quando houver problema com GPS:

1. confirmar que o modelo é GS Pro;
2. orientar teste em ambiente aberto;
3. aguardar aquisição do sinal;
4. confirmar atividade/modo esportivo utilizado;
5. verificar atualizações quando aplicável.

Ambientes como:

- prédios altos
- interiores
- árvores densas

podem interferir no sinal.

Se persistir:

encaminhar para suporte.

## Suporte inicial — carregamento

O GS Pro utiliza contato magnético para carregamento.

Se não estiver carregando:

1. verificar contatos limpos;
2. verificar se os contatos estão secos;
3. verificar encaixe do carregador;
4. utilizar fonte adequada e compatível;
5. verificar se aparece sinal de carregamento.

Não recomendar carregador turbo sem compatibilidade oficial confirmada.

Se não houver resposta após verificações básicas:

encaminhar para suporte humano.
