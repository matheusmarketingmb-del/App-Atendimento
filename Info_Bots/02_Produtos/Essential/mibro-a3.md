## Suporte inicial — conexão

Se o cliente relatar que o A3 não conecta:

1. confirmar que está utilizando o Mibro Fit;
2. verificar Bluetooth do celular;
3. verificar permissões do Mibro Fit;
4. verificar se há vínculo anterior do relógio;
5. confirmar Android/iOS quando necessário;
6. seguir orientações oficiais disponíveis na Knowledge.

Não repetir uma etapa que o cliente já informou ter realizado.

Se não resolver após verificações básicas, encaminhar para suporte humano.

## Suporte inicial — notificações

Se o cliente não recebe notificações:

verificar:

- Bluetooth conectado
- Mibro Fit ativo
- permissões de notificações
- acesso às notificações no Android quando aplicável
- aplicativo específico autorizado
- restrições de bateria/segundo plano do smartphone

Se o problema persistir, encaminhar para suporte.

## Suporte inicial — carregamento

Em caso de falha de carregamento:

1. verificar se os contatos estão limpos;
2. verificar se estão secos;
3. conferir encaixe do carregador;
4. testar fonte adequada e compatível;
5. observar se aparece algum sinal na tela.

Não recomendar carregador turbo quando não houver compatibilidade oficialmente confirmada.

Se continuar sem carregar:

encaminhar para suporte humano.
