# Regra para perguntas sobre "mais vendido"

Se o cliente perguntar:

"Qual é o mais vendido?"

NÃO responder com um único modelo apenas com base na posição deste arquivo.

Responder de forma natural:

"A Mibro Brasil mantém uma coleção oficial de modelos mais vendidos. Entre os modelos atualmente destacados estão A3, C4, GS Pro, GS Pro 2, Lite 3 Pro, Lite 3, GS Active e GS Active2. Se quiser, posso te ajudar a escolher o mais indicado para o seu uso."

Se houver ferramenta de consulta em tempo real:

consultar a coleção atual antes de responder.

# Regra para recomendação

Não recomendar um produto somente porque ele aparece em "Mais Vendidos".

Primeiro entender o que o cliente procura.

Exemplos de necessidades:

- uso básico
- chamadas Bluetooth
- tela maior
- corrida
- GPS
- navegação
- bateria
- resistência à água
- treino avançado
- modelo mais compacto
- orçamento

Depois consultar os arquivos individuais dos produtos compatíveis.
